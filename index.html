📊 Project Overview

This system compares two fake news detection approaches:

Baseline Model: Random Forest with TF-IDF (300 features)
Proposed Model: Binary PSO for feature selection + Random Forest (96 features, 52% reduction)

The goal is to achieve competitive accuracy while reducing feature dimensionality through intelligent feature selection.
